G検定　シラバス用語確認ツール

🎯 人工知能 ★★★★★
定義：人間の知的能力を人工的に実現する技術・研究分野
ポイント：統一された定義は存在しない、研究者や時代で定義が異なる
レベル分類：①制御プログラム ②古典的AI ③機械学習 ④深層学習
区別：AI＝知能（ソフト）、ロボット＝身体（ハード）
📚 機械学習 ★★★★★
定義：AIを実現する手法の一つ、データからルールを自動学習
パラダイムシフト：人間がルールを教える → 機械がデータから学ぶ
大別：教師あり学習・教師なし学習・強化学習の3種類
意義：知識獲得のボトルネックを解消
包含関係：AI ＞ 機械学習 ＞ ディープラーニング（最頻出）
🧩 ディープラーニング ★★★★★
定義：機械学習の一手法、多層ニューラルネットワークを用いる
最大の特徴：特徴表現学習を実現、人間による特徴量設計が不要
歴史：2012年 AlexNet が第三次AIブームの起爆剤
試験ポイント：「DLは機械学習に含まれる」は○、「AIと同義」は×
🌐 AI効果 ★★★★
定義：AIが実現すると、もはやAIと呼ばれなくなる現象
事例：チェスAIが人間を超えた途端「ただの探索だ」と言われる
試験ポイント：「AIの定義が変遷する理由」として出題
⚙️ エージェント ★★★
定義：環境を認識し自律的に行動する主体
仕組み：センサーで感知、アクチュエータで環境に働きかける
事例：自動運転車、ゲームAI、チャットボット
キーワード：環境と相互作用する
🎯 強いAIと弱いAI ★★★★★
弱いAI：特定タスクのみ実行、現在実現しているAIはすべてこれ。翻訳AI、囲碁AI
特徴：見かけ上知的だが、理解はしていない（中国語の部屋が示す）
強いAI（AGI）：人間のような汎用的知能・意識を持つ。現時点では未実現
試験鉄板：現在実現しているのは弱いAI
📚 チューリングテスト ★★★★★
定義：機械が人間と区別できないほど自然に会話できれば知能があるとみなす
判定方法：審査員がテキストチャットで人間か機械か区別できるか
ポイント：内容の正しさではなく「人間らしく振る舞えるか」で判定
歴史：1950年 アラン・チューリングが提唱
⚠️ 中国語の部屋 ★★★★★
定義：チューリングテストへの反論、ジョン・サールによる思考実験
内容：中国語が分からない人がマニュアル通りに返答する
外からは理解しているように見えるが、本人は理解していない
核心：正しく答えられることと理解することは同じではない
意味：弱いAIの限界を示す
⚠️ フレーム問題 ★★★★★
定義：現実で起きる無限の可能性の中から、何を考慮すべきか判断が困難な問題
本質：有限の計算資源で無限の事象を扱えない
歴史：第一次AIブーム終焉の最大原因
試験ポイント：「性能が上がれば解決する」は×、本質的に無限の問題
⚠️ シンボルグラウンディング問題 ★★★★★
定義：記号と現実世界の意味をどう結びつけるかの問題
例：AIは「リンゴ」という文字列を処理できても、実体と結びついていない
ジレンマ：辞書を引いてもまた別の記号しか出てこず無限ループ
意味：身体性を持たないAIの根本的限界
解決策の例：CLIPのようなマルチモーダル
⚙️ 身体性 ★★★★
考え方：知能は身体を持ち環境と相互作用することで発達する
位置づけ：フレーム問題・シンボルグラウンディング問題へのアプローチ
核心：身体を持たず記号だけでは真の理解に至らない
⚠️ 知識獲得のボトルネック ★★★★★
定義：エキスパートシステム最大の弱点
内容：人間の専門知識をIF THENルールに落とし込むのが困難でコストが大きい
理由：専門家は暗黙知で判断しており、単純なルールにできない
歴史：第二次AIブーム終焉の直接的原因
キーワード：人間がルールを教えるアプローチの限界
🎯 トイ・プロブレム ★★★★
定義：おもちゃのように単純化された問題
事例：迷路、8パズル、ハノイの塔、ブロック積み
課題：単純な問題は解けるが、現実の複雑な問題には対応できない
試験ポイント：「トイ・プロブレムは解けるが現実は解けない」がAIの限界
💻 ルールベース機械翻訳 ★★★
定義：人間が作成した文法ルールと辞書に基づく古典的な機械翻訳手法
課題：大量のルール作成が必要、知識獲得のボトルネックにより衰退
📚 統計的機械翻訳 ★★★
定義：大量の対訳データから統計的に翻訳パターンを学習する
意義：ルールベースのボトルネックを解消
位置づけ：現在はニューラル機械翻訳に置き換わったが橋渡しとなった技術
🌐 シンギュラリティ ★★★★
定義：技術的特異点。AIが人間の知能を超え、自らより賢いAIを作り始める転換点
予測：カーツワイルは2045年と予測（あくまで予測、確定ではない）
試験ポイント：「AIが人間を支配する日」ではなく「技術進歩が爆発的に加速する点」
📜 ダートマス会議 ★★★★
歴史：1956年夏、米ダートマス大学で開催
意義：「AI」という言葉が初めて使われた歴史的会議。ジョン・マッカーシーらが主催
位置づけ：第一次AIブームの始まり。年号とマッカーシーがセットで出題
📜 ローブナーコンテスト ★★
定義：チューリングテストの大会。最も人間らしく会話できたAIに賞
課題：表面的な会話テクニックで審査員を騙すことも可能
批判：知能の本質的な評価にはならない
⚙️ 探索木 ★★★★★
定義：問題の状態空間を木構造で表現
要素：ノード＝状態、枝＝行動
位置づけ：全ての探索の前提となる最重要基礎概念
キーワード：状態空間を木で表現
📚 幅優先探索 ★★★★★
考え方：浅い階層から順に全て調べる、同じ深さを全て見てから次の深さへ
データ構造：キュー（FIFO）を使用
長所：最短経路を保証する
短所：メモリを大量に消費し爆発しやすい
キーワード：浅い順、キュー、最短保証だがメモリ大
📚 深さ優先探索 ★★★★
考え方：一本の道を可能な限り深く進み、行き止まりでバックトラックする
データ構造：スタック（LIFO）を使用
長所：メモリ効率が良い
短所：最短経路は保証されない
📚 ブルートフォース ★★★
定義：総当たり・しらみつぶし・力任せの探索
内容：全ての可能性を試す
長所：確実
短所：組合せ爆発が起き非効率
📚 モンテカルロ法 ★★★★
定義：乱数を大量に用いて近似解を推定する手法
仕組み：ランダムに試行を繰り返し、結果の平均から解を推定
応用例：MCTSとしてAlphaGoにも応用
キーワード：乱数、試行繰り返し、近似解
🧩 Mini Max法 ★★★★
用途：二人零和ゲームの定石
考え方：相手の最善手を考慮し、自分の利益を最大化する
ルール：自分はMax、相手はMinと仮定
事例：三目並べ、チェス、将棋などゲームAIの基礎
⚙️ αβ法 ★★★★
定義：Mini Max法を効率化する枝刈り手法
仕組み：探索不要な枝を早めに刈り、少ない計算量でMini Maxと同じ結果を得る
用語：α＝自分の最善手の下限、β＝相手の最善手の上限
キーワード：枝刈りで高速化、結果はMini Maxと同じ
📜 SHRDLU ★★★
歴史：1972年に開発された自然言語理解システム
内容：積み木の世界という限定された仮想世界で、自然言語の指示に従いブロックを操作
意味：限定環境だから動いた、トイ・プロブレムの事例
📜 STRIPS ★★★
用途：ロボットの行動計画を記述する手法
構成：前提条件・行動・効果の3つで記述
目的：初期状態から目標状態への手順を自動導出
位置づけ：自動計画の基礎
🎯 ハノイの塔 ★★★
内容：探索・推論の例題として頻出のパズル。3本の棒と複数の円盤
ルール：小さい円盤の上に大きい円盤を置けない
最少手数：2ⁿ − 1
意味：組合せ爆発と再帰の例
⚙️ is a / has a / part of ★★★★★
位置づけ：知識表現の最も基本的な関係性
is a：継承「カナリア is a 鳥」
has a：所有「鳥 has a 翼」
part of：部分「タイヤ part of 車」
⚙️ 意味ネットワーク ★★★★
表現方法：概念＝ノード、関係＝リンクで表現するグラフ構造
例：[カナリア] is a >[鳥] has a >[翼]
特徴：継承推論が可能
⚙️ オントロジー ★★★★
定義：概念化の明示的仕様
位置づけ：意味ネットワークの発展形、体系的・形式的・明示的
事例：WordNet、Gene Ontology
意味：知識グラフの基礎
🧩 エキスパートシステム ★
目標：専門家の知識をIF THENルール化して推論するシステム
構成：知識ベース ＋ 推論エンジン
📜 DENDRAL ★★★★★
歴史：1965年、世界初のエキスパートシステム
分野：化学。質量分析の結果から分子構造を推定
試験ポイント：最初のエキスパートシステム＝化学
📜 マイシン(MYCIN) ★★★★★
歴史：1972年、感染症診断を行うエキスパートシステム
仕組み：約600個のIF THENルールに加え、信頼度(Certainty Factor)を導入
試験ポイント：MYCIN＝医療、信頼度
💻 ワトソン ★★★
開発：IBM
歴史：2011年、クイズ番組Jeopardy!で人間王者に勝利
仕組み：自然言語で質問応答、大量の非構造データから推論
位置づけ：ディープラーニング以前のNLPの金字塔
⚠️ 東ロボくん ★★
開発：NII、2016年。偏差値57.8、東大には不合格
示した課題：膨大な知識を蓄積しても読解力を実現するのは困難
意味：シンボルグラウンディング問題の事例
📜 イライザ(ELIZA) ★★★
歴史：1966年、世界初のチャットボット
仕組み：パターンマッチングで定型文を返す
特徴：理解しているように見えるだけ、中国語の部屋の事例
🎯 Question Answering ★★★
定義：質問に対して答えを返すタスク
進化の流れ：ELIZA → ワトソン → LLM
⚠️ Cycプロジェクト ★★★
歴史：1984年に開始、常識をすべて手入力しようとした試み
例：「水は濡れている」といった常識文を人間が入力
結果：40年経っても未完、知識獲得のボトルネックの象徴
🌐 セマンティックWeb ★★★
提唱者：ティム・バーナーズ＝リー
構想：Webに意味を持たせる
基盤技術：RDF、OWL → 知識グラフへとつながる
📚 データマイニング ★★★
定義：大量データから知識を自動発見する技術
意味：Cycのような手入力から、知識を自動発見する方向への転換
事例：ビールとおむつが一緒に買われるという発見
📚 ウェブマイニング ★★
定義：Web上のデータから知識を発見する技術
3種類：テキストマイニング、リンクマイニング、利用状況マイニング
応用例：PageRankなど
⚙️ インタビューシステム ★★
目的：専門家から知識を聞き出す作業を支援するツール
評価：知識獲得のボトルネックを解消しようとした試みだが、根本解決には至らなかった
🌐 ビッグデータ ★★★★★
定義：Volume・Velocity・Varietyの3V
背景：ビッグデータ＋計算機性能向上＋アルゴリズム進化で注目
きっかけ：2010年代のスマホ・SNSによる大量データ蓄積、ImageNet1400万枚がブレイクのきっかけ
⚠️ 次元の呪い ★★★★
定義：特徴量の次元が増えると必要なデータ量が指数関数的に増大し、学習が困難になる現象
例：1次元では10個で十分だが、10次元では10¹⁰個必要になる
対策：PCAによる次元削減、特徴量選択、正則化
試験ポイント：特徴量を闇雲に増やすと精度が低下する
🧩 スパムフィルタ ★★★★
定義：迷惑メールを自動判定する代表的な機械学習の例
仕組み：ベイズ分類を用い、単語の出現確率で判定
例：「Viagra」が多いとスパム確率が高い
ルールベースとの違い：ルールベースは人間がルールを記述、機械学習は自動学習でゆらぎに対応可能
🧩 レコメンデーションエンジン ★★★★
定義：ユーザに合った商品・コンテンツを推薦する仕組み
手法：
協調フィルタリング：似たユーザの行動から推薦「これを買った人はこれも買う」
コンテンツベース：コンテンツの内容から似たものを推薦
事例：Amazon、Netflix、YouTube
🧩 統計的自然言語処理 ★★★★
定義：大量のテキストから統計的に言語を処理する
歴史の流れ：ルールベース → 統計的 → ニューラルへ
例：Google翻訳が統計的からニューラルへ移行した
🌐 人間の神経回路 ★★
生物学的モデル：ニューロンがシナプスで結合し、発火して信号を伝達する
歴史：1943年 McCulloch & Pitts が数理モデルを提案
🧩 ネオコグニトロン ★★★
提唱者：福島邦彦、1979年、日本発
構造：S細胞（特徴抽出）＋ C細胞（位置許容）の階層構造
意義：畳み込みの原型となり、CNNの直接の祖先
🧩 LeNet ★★★★
提唱者：Yann LeCun、1998年
構造：畳み込み層 ＋ プーリング層 ＋ 全結合層
応用：手書き数字MNISTの認識、郵便番号読み取り、銀行の小切手認識で実用化
意義：CNN実用化の始まり、誤差逆伝播で学習
🌐 ImageNet ★★★★★
定義：1400万枚、2万カテゴリの大規模画像データセット
意義：大量データがブレイクスルーに必須であることを示した
位置づけ：ILSVRCの基盤データ
🌐 ILSVRC ★★★★★
定義：ImageNetを用いた画像認識コンペティション（2010 2017）
歴史：2012年 AlexNetが誤り率26%→15%に圧勝し革命が起きた。2015年 ResNetは人間の認識精度を超えた
親：ImageNetを基盤とした大会
🧩 アルファ碁 ★★★★★
開発：DeepMind
技術構成：プロ棋譜による教師あり学習 ＋ 強化学習による自己対局 ＋ モンテカルロ木探索
成果：李世ドルに4勝1敗
意義：探索空間が膨大な囲碁を攻略、社会的インパクトが非常に大きい
💻 生成AI ★★★★★
定義：画像・文章・音声などを新たに生成するAI
代表モデル：
GAN（2014年 Goodfellow：敵対的生成）
Diffusion（Stable Diffusion、DALL E 2など）
LLM（ChatGPT、GPT 3/4、BERTなど）
位置づけ：ディープラーニングの応用例、大量データ・大規模モデルで実現
事例：Midjourneyによる画像生成、ChatGPTによる文章生成
課題：著作権、フェイクニュース
回帰問題 ★★★★★
│ └─ 連続値を予測。例：家の広さから価格を予測
│ 出力が数値。誤差関数はMSE
分類問題 ★★★★★
│ └─ 離散的なラベルを予測。例：スパムか否か
│ 出力がクラス。誤差関数は交差エントロピー
多クラス分類 ★★★★
│ └─ 3つ以上のクラスに分類
│ 例：手書き数字0-9の10クラス分類
│ ソフトマックス関数を使うのが主流
単回帰分析 ★★★★
│ └─ 説明変数1つで予測。y = ax + b
│ 最も基本的な回帰
重回帰分析 ★★★★
│ └─ 説明変数が複数。y = a1x1 + a2x2 + ... + b
線形回帰 ★★★★★
│ └─ 単回帰・重回帰の総称。最小二乗法で解く
ロジスティック回帰 ★★★★★
│ └─ 名前に回帰と付くが分類モデル
│ シグモイド関数で0-1の確率を出力
│ 回帰なのに分類が最頻出ひっかけ
決定木 ★★★★
│ └─ 木構造で条件分岐。解釈性が高い
│ 過学習しやすい。アンサンブルの部品
SVM ★★★★★
│ └─ マージン最大化で分離する超平面を求める
│ カーネルトリックで非線形も可能
カーネル / カーネルトリック ★★★★
│ └─ 低次元で分離できないデータを高次元に写像して線形分離
│ 高次元で直接計算せず内積だけで効率化
マージン最大化 ★★★★
│ └─ SVMの核心。境界のマージンを最大にして汎化性能向上
自己回帰モデル(ARモデル) ★★★
│ └─ 過去の自分の値で未来を予測
│ Xt = c + φ1*Xt-1 + φ2*Xt-2 + ...
ベクトル自己回帰(VARモデル) ★★★
│ └─ ARの多変量版。複数の時系列が相互に影響
アンサンブル学習 ★★★★★
└─ 複数の弱い学習器を組み合わせて強い学習器を作る
バギング ★★★★★
└─ 並列型。データを複製して並列学習して多数決
分散を減らし過学習抑制
ブートストラップサンプリング ★★★★
└─ 重複を許してランダムにサンプリング
バギングの核となる仕組み
ランダムフォレスト ★★★★★
└─ バギングの代表。決定木を多数作り多数決
過学習しにくく高精度
ブースティング ★★★★★
└─ 直列型。前の誤りを次が重点的に学習
バイアスを減らす
勾配ブースティング ★★★★★
└─ ブースティングの代表。勾配で前の誤りを修正
XGBoost, LightGBMが有名。Kaggle最強
クラスタリング ★★★★★
│ └─ 教師なし学習の代表
│ 似たデータを自動でグループ分け
│ ラベルなし。顧客セグメント分け、異常検知
k-means法 ★★★★★
│ └─ 最も有名なクラスタリング
│ k個のクラスタに分ける
│ ①k個の重心をランダム初期化
│ ②各データを最も近い重心に割当
│ ③重心を再計算 ②③を収束まで繰り返す
│ シンプルで高速
│ 弱点：kを事前決定、初期値依存、球状のみ得意
ウォード法 ★★★★
│ └─ 階層的クラスタリング 凝集型ボトムアップ
│ 最も分散増加が少ないクラスタ同士を併合
│ k-meansと違いクラスタ数を後から決められる
│ デンドログラムで可視化可能
デンドログラム(樹形図) ★★★★
│ └─ 階層的クラスタリングの結果を木構造で可視化
│ 縦軸が距離、横軸がデータ
│ どの高さで切るかでクラスタ数が決まる
│ 「切断高さでクラスタ数が決まる」が試験ポイント
次元削減 ★★★★★
│ └─ 高次元データを低次元に圧縮しつつ情報は保持
│ 次元の呪い対策、可視化、計算量削減
主成分分析(PCA) ★★★★★
│ └─ 線形の次元削減の王道
│ 分散が最大になる方向を見つける
│ 寄与率で情報保持量が分かる
│ 可視化で2次元に落とすのによく使う
│ 「線形変換」「分散最大」「寄与率」
特異値分解(SVD) ★★★★
│ └─ 行列を U Σ V^T に分解
│ PCAの計算の中核
│ レコメンデーションや次元削減の基礎
│ 「行列分解の一種」「PCAと密接に関連」
t-SNE ★★★★
│ └─ 非線形の次元削減・可視化手法
│ 高次元を2-3次元に落として可視化が得意
│ 局所的な構造を保持、クラスタが綺麗に分かれる
│ PCAより可視化性能高いが計算コスト大
│ あくまで可視化用
多次元尺度構成法(MDS) ★★★
│ └─ データ間の距離をなるべく保持したまま低次元に配置
│ 「距離を保持して次元削減」がキーワード
トピックモデル ★★★★
│ └─ 文書の潜在的なトピックを発見
│ 文書は複数トピックの混合と仮定
│ 例：ニュース記事が政治30%+経済70%に分解
潜在的ディリクレ配分法(LDA) ★★★★
│ └─ トピックモデルの代表手法
│ 文書→トピック分布、トピック→単語分布をディリクレ分布でモデル化
│ 大量文書から自動でトピック抽出、ラベル不要
協調フィルタリング ★★★★★
└─ 似たユーザーは似たものを好むに基づく推薦
行動履歴から推薦 例：Amazon
「この商品を買った人はこんな商品も買っています」
SVDやk-NNが使われる G検定最頻出
コンテンツベースフィルタリング ★★★★
└─ アイテムの特徴に基づく推薦
例：アクション映画好きにアクション映画を推薦
協調フィルタリングと対比「アイテムの特徴を使う」
コールドスタート問題 ★★★★
└─ 協調フィルタリング最大の弱点
新規ユーザーや新規アイテムは履歴がないため推薦不可
対策：コンテンツベースと組み合わせるハイブリッド
「履歴がないと推薦できない」
マルコフ決定過程 ★★★★★
│ └─ 強化学習を定式化する数学的枠組み MDP
│ 要素：状態S、行動A、報酬R、遷移確率P、割引率γ
│ 「次の状態は現在の状態と行動のみで決まるマルコフ性」が前提
│ エージェントは環境と相互作用し報酬を最大化
│ 「S,A,R,P,γの5要素」が頻出
状態価値関数 ★★★★★
│ └─ V(s)：状態sにいる時に得られる将来の報酬の期待値
│ 「その場所がどれだけ良いか」を表す
│ 良い状態なら価値が高い、ベルマン方程式で更新
行動価値関数 ★★★★★
│ └─ Q(s,a)：状態sで行動aを取った時に得られる将来の報酬の期待値
│ Q関数とも「その状態でその行動を取るのがどれだけ良いか」
│ Q学習で学習する対象
│ 「Q(s,a)は状態と行動のペアの価値」がキーワード
割引率 ★★★★
│ └─ γ：将来の報酬をどれだけ割り引くか 0〜1の値
│ γ=0 目先の報酬のみ重視、γ=1 将来も同等に重視
│ 「遠い将来の報酬は不確実なので割り引く」
│ MDPの重要パラメータ
方策勾配法 ★★★★★
│ └─ 方策Policy πを直接学習するアプローチ
│ 方策＝状態から行動への確率分布
│ 価値関数を経由せず報酬が高くなるように勾配上昇で更新
│ 連続行動や確率的方策が扱いやすい
│ REINFORCE, Actor-Criticの基礎
REINFORCE ★★★★
│ └─ 方策勾配法の最も基本的なアルゴリズム
│ モンテカルロ法で方策勾配を推定
│ エピソード終了後に得られた報酬で方策を更新
│ シンプルだが分散が大きい
│ 「モンテカルロ方策勾配法」として出題。レインフォース
Actor-Critic ★★★★
│ └─ 方策勾配法 + 価値関数を組み合わせたハイブリッド
│ Actor：方策を担当 行動を決める役者
│ Critic：価値関数を担当 評価する批評家
│ REINFORCEの分散が大きい問題をCriticで低減
│ 現在の強化学習の主流アーキテクチャ
Q学習 ★★★★★
│ └─ 行動価値関数Qを学習する代表的手法 オフポリシー
│ Q(s,a) ← Q(s,a) + α[r + γ max Q(s',a') - Q(s,a)]
│ 「maxを取る」ので実際に取った行動と関係なく最適Qを学習
│ DQNの基礎、G検定最頻出の強化学習アルゴリズム
SARSA ★★★★
│ └─ Q学習と似るがオン・ポリシー
│ Q(s,a) ← Q(s,a) + α[r + γ Q(s',a') - Q(s,a)]
│ maxではなく実際に次の行動a'のQを使う
│ 名前の由来 S,A,R,S',A'の5つ組で更新
│ Q学習(オフポリシー) vs SARSA(オン・ポリシー)がひっかけ最頻出
バンディットアルゴリズム ★★★★
└─ 多腕バンディット問題を解くアルゴリズム群の総称
複数のスロットマシンからどれを引くか
「探索(まだ試していない腕を試す)」と
「活用(今一番良い腕を引き続ける)」のバランスが核心
ε-greedy方策 ★★★★★
└─ 最も基本的な探索手法
εの確率でランダム行動(探索)、1-εで最良行動(活用)
例：ε=0.1なら10%ランダム、90%貪欲に最良手
「εでランダム探索」がキーワード
UCB方策 ★★★★
└─ Upper Confidence Bound
不確実性が高い行動を優先的に探索
「まだ試していない=不確実性が高い」行動にボーナスを与えて探索を促す
ε-greedyより賢い探索、理論的に優れた手法
ホールドアウト検証 ★★★★★
│ └─ データを訓練:検証:テストに分割、例 6:2:2
│ 親：最も基本的な検証方法
│ 課題：データ量少ないと分割で偏りが生じる
交差検証 ★★★★★
│ └─ 定義：データを分割して複数回評価する方法の総称
k-分割交差検証 ★★★★★
│ └─ 定義：k個に分割し k-1個で学習1個で評価をk回繰り返し平均を取る
│ 例：5分割なら4:1で5回
│ 利点：データ効率的 小データで有効
オッカムの剃刀 ★★★★
│ └─ 定義：同じ精度なら単純なモデルを選ぶべきという原則
│ 親：モデル複雑さ上げるメリットは表現力向上、デメリットは過学習リスク
混同行列 ★★★★★
│ └─ 定義：予測と正解の組み合わせ 2x2表で整理
真陽性・真陰性 ★★★★★
│ └─ 真陽性TP：正を正と予測
│ 真陰性TN：負を負と予測
│ 正解に該当
偽陽性・偽陰性 ★★★★★
│ └─ 偽陽性FP：負を正と誤予測 第一種過誤、空振り
│ 偽陰性FN：正を負と誤予測 第二種過誤、見逃し
│ 例：がん検診で偽陽性は健康な人を患者と誤診、偽陰性は患者を見逃す
正解率・適合率・再現率・F値 ★★★★★
│ └─ 正解率Accuracy：(TP+TN)/全体 全体でどれだけ正解か
│ 適合率Precision：TP/(TP+FP) 正と予測した中で本当に正の割合
│ 再現率Recall：TP/(TP+FN) 本当は正のうち正と予測できた割合
│ F値：適合率と再現率の調和平均、両方考慮
│ 例：スパム検出は適合率重視、がん検診は再現率重視
ROC曲線・AUC ★★★★
│ └─ ROC：横軸偽陽性率、縦軸真陽性率で閾値変化をプロット
│ AUC：ROC曲線下面積 1に近いほど良いモデル
│ 親：閾値に依存しない評価
平均二乗誤差 MSE ★★★★★
│ └─ 定義：(予測-正解)2乗の平均
│ 特徴：外れ値に弱い、大きく罰する
二乗平均平方根誤差 RMSE ★★★★
│ └─ 定義：MSEの平方根
│ 特徴：元の単位に戻る、解釈しやすい
平均絶対値誤差 MAE ★★★★
│ └─ 定義：(予測-正解)絶対値の平均
│ 特徴：外れ値に強い、中央値に対応
赤池情報量規準 AIC ★★★★
│ └─ 定義：-2*対数尤度+2*パラメータ数
│ 特徴：小さいほど良い、予測精度重視
│ 親：複雑さにペナルティ与える
ベイズ情報量規準 BIC ★★★★
│ └─ 定義：-2*対数尤度+log(n)*パラメータ数
│ 特徴：AICよりペナルティ大きい 単純なモデル選びやすい
│ 親：データ数nが増えるとペナルティ増
過学習 ★★★★★
└─ 定義：訓練データに適合しすぎて汎化性能が低下する現象
原因：モデル複雑すぎ、データ少なすぎ
具体例：訓練誤差0.01だがテスト誤差0.5のように乖離
対策：正則化、交差検証、早期終了、データ拡張、ドロップアウト
単純パーセプトロン ★★★
│ └─ 定義：入力層+出力層のみ 単層のニューラルネット
│ できること：線形分離可能な問題のみ、AND ORは可
│ できないこと：XORは不可 1969年Minsky指摘で冬の時代へ
隠れ層・入力層・出力層 ★★★★★
│ └─ 入力層：データ受け取る層
│ 隠れ層：中間層、特徴抽出を担う 層が増えると表現力向上
│ 出力層：結果を出力する層
│ 流れ：入力→隠れ→出力の順に情報伝達
多層パーセプトロン MLP ★★★★★
│ └─ 定義：隠れ層を1層以上持つニューラルネット、3層以上でディープラーニングと呼ぶ
│ 特徴：非線形分離可能、XORも可 隠れ層増やすと複雑な関数近似可能
│ 関係：単純パーセプトロンに隠れ層追加
CPU ★★★
│ └─ 特徴：汎用プロセッサ、逐次処理得意 制御が複雑な処理向け
│ 前処理などに使用
GPU ★★★★★
│ └─ 特徴：並列処理得意、数千コア持つ 行列演算が高速
│ 理由：ニューラルネットは行列積大量 GPUが学習・推論に適する
│ 例：NVIDIA製、2012年AlexNetで使用し革命
TPU ★★★★
│ └─ 定義：Google開発、Tensor Processing Unit
│ 特徴：ディープラーニング専用、さらに高速 行列演算に特化
│ 関係：GPUよりさらに特化、クラウド提供
シグモイド関数 ★★★★
│ └─ 定義：0-1に出力、S字カーブ
│ 式：1/(1+exp(-x))
│ └─ 用途：二値分類の出力層で使用
│ └─ 課題：勾配消失問題起きやすい
│ 出力が0か1付近で勾配ほぼ0になる
tanh関数 ★★★★
│ └─ 定義：-1から1に出力、シグモイドの拡張
│ └─ 特徴：0中心で学習しやすい
│ └─ 課題：シグモイド同様勾配消失は起きる
│ └─ 関係：シグモイドの改良版
ReLU関数 ★★★★★
│ └─ 定義：x>0ならx、0以下なら0
│ 最も使われる活性化関数
│ └─ 利点：計算高速、勾配消失しにくい
│ 2012年AlexNetで使用され普及
│ └─ 課題：負の領域で勾配0、死んだReLU問題
│ └─ 関係：シグモイド・tanhの問題解決
Leaky ReLU関数 ★★★
│ └─ 定義：x>0はx、0以下は0.01xなど小さな勾配
│ └─ 特徴：ReLUの改良、負でも勾配0にならない
│ └─ 関係：ReLUの弱点解決、死んだReLU対策
ソフトマックス関数 ★★★★★
│ └─ 定義：出力を確率に変換、合計1になる
│ └─ 用途：多クラス分類の出力層
│ 例：3クラスなら0.7,0.2,0.1のように出力
勾配消失問題 ★★★★★
│ └─ 定義：層が深くなると勾配が0に近づき
│ 学習進まなくなる現象
│ └─ 原因：シグモイド・tanhは両端で勾配小さい
│ それが積み重なると消失
│ └─ 対策：ReLU使用、バッチ正規化、ResNetの
│ スキップ結合、適切な初期化
平均二乗誤差関数 MSE ★★★★★
│ └─ 定義：(予測-正解)2乗平均
│ └─ 用途：回帰問題で使用
│ └─ 特徴：外れ値に弱い、微分可能
交差エントロピー ★★★★★
│ └─ 定義：-Σ正解*log(予測)
│ └─ 用途：分類問題で最も使用される
│ └─ 特徴：確率分布のずれを測る
│ 予測が外れるほど大きく罰する
│ └─ 例：正解1で予測0.1なら-log0.1=2.3で大
カルバック・ライブラー情報量 KL ★★★★
│ └─ 定義：2つの確率分布の違いを測る
│ └─ 用途：VAE、情報理論で使用
│ └─ 特徴：非対称、KL(P||Q)とKL(Q||P)は異なる
│ └─ 関係：交差エントロピー=H(P)+KL(P||Q)
Contrastive Loss ★★★
│ │ └─ 定義：似たペアは近く、異なるペアは遠く
│ │ └─ 用途：顔認証、類似画像検索
│ │ └─ 仕組み：同じ人は距離小さく、違う人は
│ │ マージン以上離す
Triplet Loss ★★★
│ └─ 定義：アンカー、ポジティブ、ネガティブの
│ 3つ組で学習
│ └─ 用途：顔認証FaceNetで使用
│ └─ 仕組み：アンカーとポジティブは近く
│ アンカーとネガティブは遠くする
│ └─ 関係：Contrastive Lossの発展版
正則化 ★★★★★
│ └─ 定義：過学習防ぐための汎用手法総称
L0正則化 ★★
│ └─ 定義：0でないパラメータ数を罰する
│ └─ 特徴：最も直接的だが計算困難NP困難
│ └─ 用途：理論的には理想だが実用少
L1正則化 ★★★★★
│ └─ 定義：重み絶対値和を罰する項追加
│ └─ 特徴：スパースになる、不要な重み0になる
ラッソ回帰 ★★★★
│ └─ 定義：L1正則化を用いた線形回帰
│ └─ 特徴：特徴量選択効果、自動で不要特徴削除
│ └─ 例：100特徴量→10特徴量のみ残る
L2正則化 ★★★★★
│ └─ 定義：重み2乗和を罰する項追加
│ └─ 特徴：重みを小さくする、0にはならない
リッジ回帰 ★★★★
│ └─ 定義：L2正則化を用いた線形回帰
│ └─ 特徴：重みを小さく、多重共線性対策
│ └─ 例：相関高い特徴量あっても安定
│ └─ 比較：ラッソは0にする、リッジは小さくする
ドロップアウト ★★★★★
│ └─ 定義：学習時にランダムにノードを無効化
│ └─ 仕組み：例えば50%の確率でノード削除
│ 毎回異なるネットワークで学習
│ └─ 効果：アンサンブル効果、過学習防止
│ └─ 推論時は全ノード使用、出力は確率で調整
│ └─ 関係：ニューラルネット特有の正則化
誤差逆伝播法 ★
│ └─ 目的・役割
│ └─ ニューラルネットの重みを効率的に
│ 更新するための手法
│ └─ 順伝播で予測→誤差計算→逆伝播で
│ 勾配計算→重み更新という流れ
連鎖律 ★★★★★
│ │ └─ 定義：合成関数の微分法則
│ │ dy/dx = dy/du * du/dx
│ │ └─ 役割：誤差逆伝播の数学的基礎
│ │ 層が深くても微分を効率的に計算可能
│ │ └─ 例：3層あれば各層の微分を掛け合わせて
│ │ 入力層までの勾配を求める
信用割当問題 ★★★★
│ └─ 定義：出力の誤差に対して各隠れ層の
│ 責任がどれくらいかを割り当てる問題
│ └─ 解決：誤差逆伝播法が解決、連鎖律で
│ 各層の寄与を計算
│ └─ 例：出力が間違ったときどの隠れ層の
│ 重みが悪かったかを特定
勾配爆発問題 ★★★★
│ └─ 定義：勾配が指数的に大きくなり発散する現象

📚 画像分類（Image Classification）★★★★★
定義：画像全体にクラスラベルを付与するタスク
基本形：1枚の画像に1つの正解ラベル
入力：画像1枚
出力：各クラスの予測確率（例：猫95%、犬3%）
例：猫、犬、車、飛行機
代表データセット：ImageNet
ILSVRC：ImageNetを用いた大規模画像認識コンテスト
2012年：AlexNetが優勝し、深層学習による画像認識の躍進を象徴する出来事となった
ビジネス例：工場の不良品分類、医療画像の正常・異常判定
評価指標：正解率（Accuracy）、Top 1誤り率、Top 5誤り率
キーワード：画像全体を分類、物体の位置は特定しない
📚 物体検出 Object Detection ★★★★★
定義：何がどこにあるかを検出。1枚に複数物体が存在可能。G検定最頻出
入力：画像1枚 / 出力：バウンディングボックス（矩形＋クラスラベル＋信頼度）
例：[x=120,y=80,w=200,h=300] 猫98%
仕組み：物体候補領域を提案 → 各領域を分類
代表手法：R CNNシリーズ、YOLO、SSD。小さい物体にも強い
ビジネス例：自動運転の歩行者・車両検出、監視カメラの侵入検知
🎯 IoU Intersection over Union ★★★★★
定義：予測BOXと正解BOXの重なり率。0.5以上で正解とみなすのが一般的
用途：物体検出の合否判定に使用
🎯 mAP mean Average Precision ★★★★★
定義：クラスごとのAP（適合率 再現率曲線下面積）を平均した値
用途：物体検出の標準評価指標
📚 セマンティックセグメンテーション ★★★★★
定義：ピクセル単位でクラスを塗り分ける
入力：画像 / 出力：ピクセルごとのクラスIDマップ
例：空、道路、建物、人、車…と塗り分け
特徴：同じクラスの個体は区別しない。人が2人いても両方「人」クラス、別IDは振らない
代表手法：FCN、U Net、DeepLab、PSPNet
ビジネス例：自動運転の走行可能領域検出、医療画像の臓器領域抽出、衛星画像の土地被覆分類
評価指標：ピクセル精度、IoU、mean IoU
キーワード：ピクセル単位、個体は区別しない
📚 インスタンスセグメンテーション ★★★★★
定義：個体まで区別して塗り分ける、セマンティックの発展版
入力：画像 / 出力：ピクセルごとのクラス＋個体ID
例：人2人 →「人1」「人2」と別IDで塗り分け
位置づけ：物体検出とセグメンテーションの統合タスク
代表手法：Mask R CNN ★★★★★。Faster R CNNにマスク予測ブランチ追加、物体検出と同時にマスク予測
ビジネス例：工場の部品個数カウント、細胞の個体カウント、人物の切り抜き
評価指標：mAPをマスクのIoUで算出
キーワード：個体まで区別、Mask R CNN
試験ポイント：セマンティックとの違いが必ず問われる
📚 パノプティックセグメンテーション ★★★★
定義：セマンティック＋インスタンスを統合した最新タスク、2018年 Kirillov提案
特徴：画像の全ピクセルを漏れなく分割、最も情報量が多い
考え方：
Stuff：数えられないもの（空、道路、草）→ セマンティック的に塗り分け
Things：数えられるもの（人、車、犬）→ インスタンスとして区別
両者を統合し画像全体を完全に分割
入力：画像 / 出力：全ピクセルのクラス＋Thingsには個体ID
ビジネス例：自動運転の完全シーン理解、画像編集の完全な領域分割
評価指標：PQ Panoptic Quality
キーワード：全ピクセルを漏れなく、StuffとThings統合、2018年
📚 姿勢推定 / OpenPose ★★★★
定義：人の関節位置を推定するタスク、人体姿勢推定 Human Pose Estimation
入力：画像または動画 / 出力：関節の2D/3D座標
例：肩、肘、手首、腰、膝、足首など18点など
種別：単一人姿勢推定、複数人姿勢推定（難易度高）
代表手法：OpenPose ★★★★、2017年 CMU提案、複数人リアルタイム姿勢推定の王道
仕組み：
① Part Confidence Mapsで関節位置を検出
② Part Affinity Fields PAFsで関節の繋がりを学習（例：肘と手首が同じ人のものか判定）
③ 二部グラフマッチングで個人に紐付け、ボトムアップ方式で人数に依らず高速
ビジネス例：スポーツフォーム解析、リハビリ動作解析、VTuberのモーションキャプチャ、監視カメラの転倒検知
評価指標：PCK、OKS Object Keypoint Similarity
キーワード：関節座標、PAFsで繋がり学習、OpenPoseは複数人リアルタイム

🎯 2段階検出 vs 1段階検出 違い ★★★★★
試験鉄板：この違いは必ず出る
2段階検出：
① 領域提案で物体がありそうな場所を約2000個探す
② その領域を1つずつ分類し矩形を補正
代表：Fast R CNN、Faster R CNN
特徴：高精度だが低速、医療画像や工場検査など精度必須の現場で現役
1段階検出：
領域提案を飛ばし、1回のCNNで矩形と分類を同時に予測
代表：YOLO、SSD
特徴：超高速だが2段階よりやや低精度、自動運転や監視カメラなどリアルタイム必須の現場で採用
キーワード：2段階は高精度低速、1段階は高速やや低精度
🧩 Fast R CNN 2段階の高速化 ★★★★
旧R CNNの欠点：領域提案2000個を2000回CNNに通すため遅すぎる（47秒/枚）
革新点：
① 画像1枚を1回だけCNNで特徴抽出
② RoIプーリングで2000個の領域を特徴マップから切り出し
③ 全結合層で分類＋矩形補正
成果：学習も推論も約100倍高速化
課題：領域提案はまだSelective Searchに依存
キーワード：画像1回CNN、RoIプーリング、100倍高速
🧩 Faster R CNN 2段階の完成形 ★★★★★
開発：2015年 Shaoqing Ren氏ら、2段階法の完成形
革新点：RPN（Region Proposal Network）で物体がありそうな場所を自ら予測
仕組み：アンカーボックスを多数配置し、物体らしさと矩形補正を出力
効果：Selective Searchが不要、完全エンドツーエンド学習可能
現在でも医療・工場検査で現役
キーワード：RPN、領域提案もニューラルネットワーク、試験鉄板
⚙️ FPN 特徴ピラミッド ★★★★★
開発：2017年 Tsung Yi Lin氏ら、現在ほとんどの検出器に標準装備
問題点：大きな特徴マップは高解像だが浅い、小さな特徴マップは低解像だが深い。従来は小物体の検出が苦手
解決策：トップダウン経路と横方向結合、深い小さなマップを拡大し浅い大きなマップと足し算
効果：小物体の検出性能が劇的に改善、COCOで数％向上
キーワード：トップダウン＋横結合、小物体改善、標準装備

特徴：領域提案なし、1回のCNNで全て終わる
効果：超高速（45fps〜155fps）、自動運転・監視カメラで採用
バージョン：v2でアンカー導入、v3でFPN導入
キーワード：1回だけ見る、グリッド分割、超高速
🧩 SSD ★★★★

核心：複数スケールの特徴マップを使い、異なる大きさの物体を検出
仕組み：小さい特徴マップで大きな物体、大きな特徴マップで小さな物体を検出、アンカーを多スケールに配置
効果：YOLOより高精度、Faster R CNNより高速、バランス型
キーワード：多スケール特徴マップ
🧩 FCN 全畳み込み ★★★★★
開発：2014年 Jonathan Long氏ら、セグメンテーションの原点
核心：全結合層を畳み込み層に置換

│ └─ 🎯 情報検索・文書表現の最重要基礎 G検定最頻出
│ ⚙️ TF-IDF = TF × IDF
│ TF Term Frequency：単語の出現頻度
│ 文書内でよく出るほど高い
│ IDF Inverse Document Frequency：逆文書頻度
│ 珍しい単語ほど高い
│ ⚙️ 数式：IDF = log 全文書数 / その単語を含む文書数
│ 例：the は など全ての文書に出る→IDF低
│ 深層学習など特定文書のみ→IDF高
│ 効果：珍しい単語ほど高スコア 重要単語を強調
│ 単なる回数 BoWより文書特徴を的確に表現
│ 💻 用途：情報検索のランキング
│ 文書類似度 キーワード抽出
│ 試験鉄板：珍しい単語ほど高スコア→TF-IDF
│ TFは出現頻度 IDFは逆文書頻度

　　　　　 H0 棄却したい仮説 「差がない」という仮説
│ ├─ 📈 対立仮説 ★★★★
　　　　　H1 主張したい仮説 「差がある」
│ │ └─ p値<0.05で帰無仮説棄却→対立仮説採択が有意差あり
│ └─ 📈 相互情報量 ★★★★

│ ├─ 📈 共分散 ★★★★
　　　　　2変数が一緒に増えるか 符号だけでは強さ不明
│ ├─ 📈 相関係数 ★★★★★

│ ├─ 📈 偏相関係数 ★★★★
　　　　　第3変数の影響を除いた相関 疑似相関を見破る
│ │ └─ アイス売上と溺死数は相関あるが真の原因は気温 気温を除くと相関消える
│ ├─ ⚠️ 疑似相関 ★★★★★

│ │ └─ 試験：「相関は因果を意味しない」これが頻出
│ ├─ 📈 ユークリッド距離 ★★★★★

│ ├─ 📈 マハラノビス距離 ★★★★
